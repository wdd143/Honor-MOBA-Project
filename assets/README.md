# Assets

This folder is reserved for licensed, imported game assets.

Expected subfolders:
- models/hero
- models/minions
- models/monsters
- animations
- textures
- fx

The current project builds temporary 3D meshes and VFX procedurally in scripts/procedural_assets.gd and scripts/game.gd. See docs/ASSET_PIPELINE.md before adding external files. Keep a source and license record for every imported pack.
