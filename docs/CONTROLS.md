# Controls and first launch

1. Open Godot 4.x.
2. Click Import.
3. Select `project.godot` in the extracted repository folder.
4. Import and open the project.
5. Press Play Project.

| Key | Action |
| --- | --- |
| W/A/S/D | Move |
| Space | Basic attack |
| Q | Area skill |
| R | Restart |

The scene builds its arena and placeholder units at runtime. No asset import is required.
