# Controls and first launch

1. Install Godot 4.x Standard.
2. Open Godot and click **Import**.
3. Select project.godot in the extracted repository folder.
4. Import and open the project.
5. Press **F5** to run the project. Press **F6** to run the current main scene.

| Key | Action |
| --- | --- |
| W/A/S/D | Move |
| Space | Sword attack (nearest enemy minion or jungle monster) |
| Q | Wind Nova area skill |
| R | Restart after a core is destroyed |

The arena, procedural hero, lane soldiers, jungle golems, towers, trees and first-pass effects are created at runtime. No third-party asset pack is required for this prototype.
